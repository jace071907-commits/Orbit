# ORBIT Dashboard

ORBIT (Operational Reporting, Business Intelligence & Tracking) is a web-based leadership and operational dashboard used for Payment Integrity reporting and management.

## Features

- Overview Dashboard
- Daily Detail
- Monthly Performance
- Leadership Portal
- Executive Alerts
- Recognition Watchlist
- PIP Watchlist
- Associate Records
- My Notes

## Data Pipeline

Excel
→ Refresh_ORBIT.ps1
→ orbit-data.js
→ ORBIT Dashboard

## Source Control Notes

This repository intentionally excludes:

- orbit-data.js
- orbit-auth.js
- Raw CSV exports
- Excel source files
- Employee performance data
- Authentication exports

Generated data remains within the operational environment and is not stored in GitHub.
